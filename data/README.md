# Data

The dataset is not included in this repository. Download the IBM Telco Customer Churn file
(7,043 rows, 21 columns, `Churn` target) and save it here as `Telco-Customer-Churn.csv`.

- Kaggle: search for "Telco Customer Churn" (IBM sample data)
- IBM sample-data repository: https://github.com/IBM/telco-customer-churn-on-icp4d

Check the source's terms before redistributing the file. The CSV is git-ignored by default.
